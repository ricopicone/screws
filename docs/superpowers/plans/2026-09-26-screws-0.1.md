# `screws` 0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `screws` 0.1: MR chapters 3 to 6 as snake_case functions with MR aliases, a `Robot` class, a URDF loader, the UR5 and RRP robots, testing helpers, and the CoppeliaSim bridge (`Scene`, `Arm`, `Log`) without scene inertias.

**Architecture:** One module per MR chapter group (`so3`, `se3`, `kinematics`), each a set of pure numpy functions that are the reference implementation. `Robot` is a frozen dataclass whose methods delegate to them. `urdf` builds a `Robot` from XML; `robots` ships two. `aliases` binds MR's names. `coppelia` is imported only on demand and talks to CoppeliaSim through an injected `sim` object so its logic tests against a fake.

**Tech Stack:** Python >= 3.10, numpy, `uv`, `hatchling`, `pytest`, `ruff`. Extras: `coppeliasim-zmqremoteapi-client==2.0.4` (`[coppelia]`), `matplotlib` (`[plot]`). Dev: `modern_robotics==1.1.1` for cross-checks.

**Spec:** `docs/superpowers/specs/2026-09-26-screws-package-design.md`. Read §2 (conventions), §3 (name table), §4 (Robot), §5 (URDF), §8 (bridge) before the matching task. Where plan and spec disagree, the spec wins.

## Global Constraints

- Every array-returning function returns `float64` `ndarray`; every array argument goes through `np.asarray(x, dtype=float)`.
- Screw-axis lists are **6xn, axes as columns**. No function infers orientation. Sequence-of-vectors entry points stack with `np.column_stack`.
- Argument names: MR's single letters stay (`M`, `S`, `B`, `theta`, `T`, `R`, `p`); MR's compounds become words (`tol_omega`, `tol_v`, `F_tip`, `link_frames`, `link_inertias`).
- `exp3`/`exp6` take the bracketed matrix; `log3`/`log6` return it.
- Aliases: same object where signatures match; thin wrapper with MR's exact signature and return otherwise; no warnings.
- Every public docstring ends with a citation line, e.g. `MR 3.2.3; notes 3.6 (Exponential coordinates of rotations)`.
- `import screws` must not import `zmq`, `cbor2` or `matplotlib`.
- Every module that carries MR code starts with the MR copyright notice (in `LICENSE` as well).
- Commands run as `uv run pytest`, `uv run ruff check .`. Never install into an ambient environment.
- Defaults are MR's: `near_zero` threshold `1e-6`, IK `max_iter=20`, IK tolerances `tol_omega=1e-3`, `tol_v=1e-4`.

## Review Focus

Inputs the spec implies but no obvious test covers; each is pinned to the task named.

1. **A 6x6 screw-axis array passed where a sequence is expected** (n = 6 UR5) must be treated as six columns, never transposed; `Robot.from_screw_axes` must reject a 2-D array and demand a sequence. (Task 5)
2. **Zero rotation and half-turn in `log3`/`log6`**: `R = I` returns zeros; `R` with trace `-1` returns a `pi` rotation without division by zero. (Task 2, Task 3)
3. **A prismatic screw axis through `exp6`** (`omega = 0`) must be a pure translation `v * theta`, not a formula that divides by `|omega|`. (Task 3)
4. **URDF with several leaf links or several roots** must raise naming the candidates, not silently pick one. (Task 6)
5. **Bridge command in the wrong mode** (torque command while `mode == "position"`) must raise, not silently set a position; and a failed connection must raise `SimulatorNotRunning` with the student-facing sentence. (Task 10)

```python
def revolute_axis(q, s_hat):
    """Zero-pitch screw axis (omega, v) = (s_hat, -s_hat x q) through the point q.
    Addition; the joint-frame derivation of notes 4.1. MR 3.3.2.2."""
    q, s_hat = np.asarray(q, float), np.asarray(s_hat, float)
    return np.concatenate([s_hat, -np.cross(s_hat, q)])

def prismatic_axis(s_hat):
    """Infinite-pitch screw axis (0, s_hat). Addition. MR 3.3.2.2."""
    return np.concatenate([np.zeros(3), np.asarray(s_hat, float)])

def trans(p):
    """Trans(p): pure translation. Addition. MR 3.3.1; notes 3.4."""
    T = np.eye(4); T[:3, 3] = np.asarray(p, float); return T
```

```python
@dataclass(frozen=True)
class IKResult:
    theta: np.ndarray; converged: bool; iterations: int; history: np.ndarray
    error_omega: float; error_v: float

def ik_body(M, B, T, theta0, *, tol_omega=1e-3, tol_v=1e-4, max_iter=20):
    M, B, T = (np.asarray(a, float) for a in (M, B, T))
    theta = np.asarray(theta0, float).copy(); hist = [theta.copy()]
    def twist(th): return se3_to_vec(log6(transform_inv(fk_body(M, B, th)) @ T))
    Vb = twist(theta); i = 0
    err = np.linalg.norm(Vb[:3]) > tol_omega or np.linalg.norm(Vb[3:]) > tol_v
    while err and i < max_iter:
        theta = theta + np.linalg.pinv(jacobian_body(B, theta)) @ Vb; i += 1
        hist.append(theta.copy()); Vb = twist(theta)
        err = np.linalg.norm(Vb[:3]) > tol_omega or np.linalg.norm(Vb[3:]) > tol_v
    return IKResult(theta, not err, i, np.array(hist), float(np.linalg.norm(Vb[:3])), float(np.linalg.norm(Vb[3:])))
```

`joint_frames`: accumulate `T = T @ exp6(vec_to_se3(S[:, i] * theta[i]))` and append `T @ M_joints[i]`. `manipulability(J)`: for each 3xn block `A = Jblock @ Jblock.T`, eigenvalues `lam` sorted; `mu1 = sqrt(lam_max / lam_min)`, `mu2 = lam_max / lam_min`, `mu3 = sqrt(det(A))`; return `{"angular": ..., "linear": ...}`.
